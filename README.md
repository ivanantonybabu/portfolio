# Ivan Antony Babu — Engineering Portfolio

Personal portfolio website for **Ivan Antony Babu**, Robotics & Embedded Systems Engineer (CUSAT & IIT Madras, IIT Tirupati STAR-PNT Fellow).

🌐 **Live Website:** [https://ivanantonybabu.github.io/portfolio/](https://ivanantonybabu.github.io/portfolio/)

---

## ⚡ Tech Stack

- **Framework:** React 18 + TypeScript + Vite
- **Styling:** Tailwind CSS + Custom CSS Variables (Midnight + Arctic Blue theme)
- **Animations:** Framer Motion + Infinite Marquee Tickers + HTML5 Canvas
- **Icons:** Lucide React
- **Deployment:** GitHub Pages via GitHub Actions CI/CD (`.github/workflows/deploy.yml`)
